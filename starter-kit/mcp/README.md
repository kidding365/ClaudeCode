# MCP templates

## Short description
Reusable MCP configuration examples for research-intensive ClaudeCode workflows.

## Long description
This folder contains a project-level MCP config template showing both HTTP and stdio server styles. It is designed to bootstrap:
- external research retrieval,
- local documentation indexing,
- structured tool access through MCP without hardcoding platform logic into prompts.

Replace placeholder URLs, tokens, and local paths before use.
