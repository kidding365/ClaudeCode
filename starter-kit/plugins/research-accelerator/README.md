# research-accelerator plugin

## Short description
Plugin scaffold to operationalize focused research, safe parallel tasking, and concise answer delivery.

## Long description
This plugin bundles a research planning command, a specialized orchestrator agent, and a lean output style. Together they provide an execution layer for your process improvements:
- Convert broad prompts into bounded experiments.
- Split work into independent tracks with explicit merge contracts.
- Keep final responses compact, actionable, and low-noise.

Use this as a baseline and evolve each artifact with your team-specific constraints.
