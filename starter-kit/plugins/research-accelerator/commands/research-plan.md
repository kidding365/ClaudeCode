# Research Plan Command

## Long description
This command transforms an open-ended request into an execution-ready plan. It enforces strict scope boundaries, defines validation checkpoints, and recommends only high-yield follow-up actions.

## Instructions
1. Restate objective in one sentence.
2. Propose primary hypothesis and top 2 alternatives.
3. Define evidence sources and quality requirements.
4. Create a phased plan (Discovery, Validation, Decision).
5. Include failure criteria and pivot conditions.
6. End with the first concrete action and expected output.
